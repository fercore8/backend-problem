### Pre-loaded games your team can run immediately. No prep needed.

## How to Run a Game (60-second version)

1. Pick a game from the list below
2. Get the card image (use Scryfall.com — free, fast, no account needed)
3. Copy the opening post template from WHATSAPP_TEMPLATES.md
4. Fill in the card name and prize
5. Set a phone alarm for 1h to close it
6. Post the winner announcement when time is up

## QUICK REFERENCE — Prize Tiers

Standardise prizes so you don't have to decide each time:

| Speed of Win | Prize |
|---|---|
| First correct answer | 10% discount code on bdv-giant |
| Most creative answer (voted) | $5 store credit |
| Weekly winner (most wins) | $10–$20 store credit |
| Blitz sale first 5 buyers | Free foil rare |
| Mystery box buyer | No extra prize — box is the prize |

Keep codes simple: **BDVWIN10**, **BDVWIN15**, **BDVCREDIT5** — generate them in your bdv-giant seller dashboard ahead of time so you're never scrambling after a game ends.
