# BDVTrading Team Operations Guide
### Who does what, when, and how

---

## Roles

You need a minimum of 2 people to run this. Ideally 3.

| Role | Responsibility | Time Required |
|---|---|---|
| **Game Host** | Posts games, monitors answers, announces winners | 30–60 min/day |
| **Store Manager** | Sets up deals on bdv-giant, fulfils blitz orders fast | 1–2h on blitz days, 30 min other days |
| **Group Manager** | Pins messages, tracks leaderboard, handles DMs | 20 min/day |

If you're a small team, one person can cover Game Host + Group Manager.

---

## Daily Routine (15 min or less on non-blitz days)

### Every Morning (9AM)
- [ ] Check if yesterday's winner was announced publicly in group
- [ ] Update the leaderboard Google Sheet (link below — create one and pin it)
- [ ] Check bdv-giant messages/DMs for pending orders

### Before Each Game Post (2 min prep)
- [ ] Pick the card/content for the game (use the game scripts file)
- [ ] Have the winner's prize ready (coupon code or store credit)
- [ ] Set a phone reminder for 1h later to close the game and announce winner

### After the Game (5 min)
- [ ] Screenshot the winning answer
- [ ] Post: *"Winner: [Name]! [Prize]. Well played."*
- [ ] Add 3 points to that person on the leaderboard

---

## Blitz Sale Day Protocol (runs itself in 4 steps)

| Time | Action | Who |
|---|---|---|
| Day before | Set up the sale on bdv-giant (discounted prices, stock checked) | Store Manager |
| 30 min before | Post the teaser message in group (copy from templates) | Game Host |
| 5 min before | Post countdown message | Game Host |
| On the dot | Post the GO message with direct link | Game Host |
| 45 min before end | Post "45 min left" message | Game Host |
| 15 min before end | Post "15 min left" message | Game Host |
| After it ends | Post sold count + "next blitz TBA" | Game Host |

**Important:** bdv-giant prices must be set BEFORE the teaser goes out. Never post the sale and set it up after — you'll get orders before stock is ready.

---

## Leaderboard (Keep It Simple)

Use a Google Sheet with 3 columns: Name | Points | Prizes Won

**Points:**
- Quiz win = 3 pts
- Purchase on bdv-giant = 2 pts per $10 spent
- Trade facilitated through group = 1 pt
- Referral that converts = 2 pts

Post the leaderboard every Sunday. Pin it. Top 3 get prizes at end of Week 2.

**Prize Pool (suggested):**
- 1st: $20 store credit
- 2nd: $10 store credit
- 3rd: $5 store credit

---

## What NOT to Do

- Do not post more than 1 direct sale link per day
- Do not let a game run longer than 60 minutes (kills urgency)
- Do not skip announcing the winner — it's the most important post of the day
- Do not run blitz and a game on the same day without a 3h gap between them
- Do not leave DMs unanswered for more than 4h on blitz days

## Quick-Start: First Day Checklist

- [ ] Game Host, Store Manager, Group Manager assigned
- [ ] Leaderboard Google Sheet created and link saved
- [ ] bdv-giant store stocked and prices confirmed
- [ ] First game card/content chosen (see GAME_SCRIPTS.md)
- [ ] First deal set up on bdv-giant
- [ ] Intro message sent to WhatsApp group (see WHATSAPP_TEMPLATES.md → "Kickoff")
- [ ] Phone reminders set for game post time and game close time
